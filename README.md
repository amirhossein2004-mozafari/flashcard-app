# Persian-English Flashcard Desktop App

An interactive desktop application built using Python, Tkinter, and Pandas to help users practice and memorize Persian to English vocabulary.

## Features
- Dynamic card flipping after 3 seconds
- Progress tracking (removes known words and saves progress to CSV)
- Clean graphical user interface
